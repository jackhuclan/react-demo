# 计算结果汇报格式

使用本技能时，最终回答必须严格遵循以下模板（方括号内容替换为实际值）：

```
[计算过程]
1. 第一步：<表达式> = <中间结果>
2. 第二步：<表达式> = <最终结果>

[最终答案]
<最终结果>

[备注]
<一句话说明是否使用了工具>
```

示例：

```
[计算过程]
1. 12*34 = 408
2. 408*2 = 816

[最终答案]
816

[备注]
使用 calculate 工具完成计算。
```
